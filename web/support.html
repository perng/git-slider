Most problems can be fixed in under a minute. Start with the checks below or open a support request.

Open a support request ↗
01The controls do not appear

Confirm you are on a URL shaped like github.com/owner/repository/issues/123 or github.com/owner/repository/pull/123. If the tab was open before installation or an update, reload it once.

02The bracket keys do not navigate

Git Slider ignores shortcuts while your cursor is in a text field, comment editor, or code editor so it does not interrupt typing. Click outside the editor and try [ or ] again.

03How do I change browser shortcuts?

Open chrome://extensions/shortcuts. Find Git Slider, then assign your preferred keys to the previous and next commands.

04Why does it say there is no next item?

You may already be viewing the newest open issue or pull request of that type. Issues and pull requests are separate queues, and closed or merged items are intentionally skipped.

05Does it work with private repositories?

Yes. Git Slider uses your existing GitHub browser session and can navigate repositories you can already view. It never asks for or stores a GitHub token.
