PRIVACY POLICY

Small extension.
Small data footprint.

Git Slider is designed to navigate GitHub issue and pull-request queues without collecting user data or operating a developer-controlled server.

Information the extension processes

When you activate Git Slider on a GitHub issue or pull-request page, it temporarily reads the page URL and GitHub-provided page metadata, including the repository name, item number, item type, state, and creation time. It also requests filtered issue or pull-request lists directly from GitHub to locate the nearest open item.

How that information is used

The information is used only to provide the extension’s user-facing previous and next navigation. Processing happens locally in your browser.

Storage and retention

Git Slider does not persist browsing data, GitHub page content, or navigation history. A neighboring URL may be cached temporarily in page memory and disappears when the page or tab is closed or reloaded.

Sharing and transmission

Git Slider does not send data to the developer or to analytics, advertising, or other third-party services. Requests needed for navigation are sent only to github.com over HTTPS. Those requests are governed by GitHub’s own privacy practices.

Authentication

The extension can use the GitHub session already present in your browser so that it works with repositories you are authorized to view. Git Slider does not read, copy, store, or transmit your password, cookies, access tokens, or other authentication credentials.

Permissions

Git Slider runs only on GitHub issue and pull-request detail URLs. Access is used solely to display its navigation controls, identify the current item, request GitHub’s filtered lists, and navigate to the selected open item.

Sale, advertising, and profiling

Git Slider does not sell data, show advertising, build user profiles, track browsing behavior, or use data for credit, lending, or eligibility decisions.

Children’s privacy

Git Slider is a developer productivity tool and is not directed to children. It does not knowingly collect personal information from anyone.

Changes to this policy

If the extension’s data practices change, this page will be updated before the new practices are introduced, and the effective date above will change.

Contact and support

Questions or concerns can be submitted through the Git Slider support tracker.
