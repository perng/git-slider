## Detailed description

Stay in the issue. Move through the queue.

Git Slider adds fast previous/next navigation to GitHub issue and pull-request pages. Press one key or use one compact click target to move through open work without returning to the repository list.

Features:

- Press [ for the previous open item and ] for the next open item.
- Use a compact navigation rail directly on the GitHub page.
- Navigate from the extension toolbar popup.
- Use configurable browser-wide shortcuts.
- Stay within the current repository and item type.
- Automatically skip closed issues and closed or merged pull requests.
- Work with public and private repositories you can already access.

Git Slider does not require a GitHub API token. It has no account, analytics, advertising, or developer-operated server. Navigation is computed locally using GitHub pages requested through your existing browser session.
